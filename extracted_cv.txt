Project’s Description
This project presents an AI-driven medical imaging and simulation framework that integrates convolutional neural network–based brain tumor detection, robust MRI preprocessing and data augmentation, automated tumor localization and physics-based thermal ablation modeling by using COMSOL Software enabling accurate tumor classification (82.57% accuracy) and AI-guided bioheat simulation for non-invasive treatment analysis in a cost-effective and fully simulated environment.

Project’s Description

•Design & Development of Embedded Mechatronic System for Robotic Tele-Surgery (01/2025- 12/2025)
Project’s Description
This project presents a low-cost, AI-enabled embedded telesurgery system that integrates modular master–slave robotic teleoperation, sub-200 ms wireless control and real-time computer vision for object detection and guidance achieving reliable surgical simulation at a cost under USD 500 making advanced telesurgery training accessible for low- and middle-income settings.
